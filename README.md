Library Management System
A desktop-based Library Management System developed in Python using Tkinter for the graphical user interface and MySQL for database management.

The system provides separate functionality for Admin and Student users, including book management, student management, category management, issuing and returning books, and password management.

Database Setup
This project uses MySQL as its database.

1. Install MySQL
Make sure MySQL Server is installed and running on your computer.

2. Create the Database
Create the database used by the project. If you already have a database dump (.sql file), import it into MySQL.

For example:

CREATE DATABASE library_management_project;
Then import the provided SQL dump and its tables.

3. Configure the Database Connection
Open:

connection.py
Update the MySQL connection details according to your system:

import pymysql

mycon = pymysql.connect(
    host="localhost",
    user="root",
    password="YOUR_PASSWORD",
    database="library_management_project"
)
Replace YOUR_PASSWORD with your MySQL password.

Required Python Packages
Install the required packages using:

pip install pymysql pillow
Tkinter is normally included with Python on Windows. If it is not available, install the appropriate Tkinter package for your Python installation.

How to Run
Start MySQL Server.
Make sure the database has been imported.
Verify the credentials in connection.py.
Open the project in PyCharm, VS Code, or another Python IDE.
Run the appropriate login file:
admin_login.py
or

student_login.py
The application will open through the Tkinter GUI.

Database Connectivity
The application communicates with MySQL through PyMySQL.

The general flow is:

Tkinter GUI
     ↓
Python Module
     ↓
connection.py
     ↓
PyMySQL
     ↓
MySQL Database
Notes
MySQL must be running before using database-related features.
Make sure the database name, username, and password in connection.py are correct.
Keep the image file lib1.jpg in the project directory if it is used by the GUI.
Do not upload or publish your actual MySQL password in a public repository.
The .idea folder is generated by PyCharm and is generally not required when sharing the source code.
